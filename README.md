# CodeEcho 
AI 前端代码注释生成工具。一款面向前端开发者的轻量工具，输入前端代码（React/Vue/HTML/CSS/JS/TS），自动生成规范、易读的中文代码注释。

## 功能特性
- 支持 6 种前端代码类型：React、Vue、HTML、CSS、JavaScript、TypeScript
- 基于 Monaco Editor 的专业代码编辑体验，语法高亮、行号、自动缩进
- AI 驱动的智能注释生成，不修改原代码逻辑，只添加规范中文注释
- 左右分栏实时预览，一键复制、下载结果代码

## 技术栈
### 前端
- React 18 + TypeScript
- Vite 构建工具
- Monaco Editor 代码编辑器
